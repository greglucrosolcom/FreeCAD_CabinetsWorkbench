# Contributing

Issues, documentation improvements and tested pull requests are welcome.

1. Describe the FreeCAD version, operating system and reproducible steps.
2. Keep changes focused; avoid modifying unrelated cabinet commands.
3. Preserve internal spreadsheet identifiers and working parametric behavior.
4. Test affected commands, including save/reopen and repeated insertion.
5. Confirm that any contributed code or artwork can be released under The Unlicense (or clearly disclose any third-party license before submission).

Please do not submit files from the separately developed Advanced Cabinets Workbench unless their inclusion is explicitly authorized by the project maintainer.
