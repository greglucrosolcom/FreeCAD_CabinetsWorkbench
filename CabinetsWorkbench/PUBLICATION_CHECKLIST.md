# Public release checklist

- [ ] Verify ownership and redistribution rights for every Python module and SVG asset.
- [ ] Verify license text and metadata against the current GitHub LICENSE file.
- [ ] Replace any preexisting GitHub README with the included documentation if desired.
- [ ] Test this package on a clean FreeCAD 1.1.4 installation, without the Advanced Cabinets Workbench.
- [ ] Test command creation, parametric spreadsheets, save/reopen, and cabinet assemblies.
- [ ] Verify toolbar, workbench logo, and `package.xml` in FreeCAD Addon Developer Tools.
- [ ] Assign an initial public release version and update package.xml, changelog and Git tag consistently.
- [ ] Upload sources to the existing GitHub repository.
- [ ] Seek independent tests and follow the current FreeCAD Addon Index review procedure.

This checklist is not a substitute for a live FreeCAD or FreeCAD Addon Manager validation.
