# FreeCAD Cabinets Workbench

A parametric cabinet modeling workbench for FreeCAD, developed in Python.

The Cabinets Workbench provides commands for generating customizable cabinet geometry using FreeCAD's native Spreadsheet workbench for dimensional control.

## Features

- Parametric cabinet width, depth, height, and material thickness
- Lower, upper, and specialty cabinet configurations
- Adjustable doors, drawers, shelves, and toe kicks
- Spreadsheet-driven dimensional control
- Custom cabinet commands and toolbar icons
- Integration with FreeCAD's document model and assembly workflows
